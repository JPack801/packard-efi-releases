# Packard EFI for Windows

The remote tuning companion for Packard EFI customers. It runs on 64-bit Windows 10 and 11.

## Install or update

1. Open the [latest release](https://github.com/JPack801/packard-efi-releases/releases/latest).
2. Under **Assets**, download the file whose name ends in `Setup.exe`.
3. Run it. A newer version installs over an older one and keeps your settings.

To sign in you need the user ID and PIN that Packard EFI gave you.
