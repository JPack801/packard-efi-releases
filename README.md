# Packard EFI for Windows

The remote tuning companion for Packard EFI customers. It runs on 64-bit Windows 10 and 11.

## Install

**[Download Packard-EFI-Setup.exe](https://github.com/JPack801/packard-efi-releases/releases/latest/download/Packard-EFI-Setup.exe)** and run it. That one file is all you need, and this link always gives the newest version.

Once Packard EFI is installed it keeps itself current: when a newer version is ready, an **Update** button appears at the bottom of the app.

To sign in you need the user ID and PIN that Packard EFI gave you.
